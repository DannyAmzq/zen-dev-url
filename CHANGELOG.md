# Changelog

## 1.2.0-beta.1 — unreleased beta candidate

- Added remembered per-origin Automatic, Always on, and Always off behavior.
- Changed `Alt+Shift+D` from a temporary tab override to a remembered HTTP(S) origin choice; added `Alt+Shift+O` for settings.
- Retained custom ports, host globs, detection defaults, native URL suggestions, viewport readout, and developer settings.
- Prepared toolbar lifecycle and layout handling for current Zen testing.
- Replaced URL markup interpolation with text rendering and clarified reload behavior.
- Added installation, removal, beta testing, contribution, and outreach documentation.

Live Zen compatibility and public distribution remain subject to the [beta checklist](docs/BETA-TESTING.md). This entry does not claim a published release.

## Earlier releases

This candidate builds on the existing public [devbar repository](https://github.com/DannyAmzq/zen-dev-url) and its April implementation. It is not the project's first public source release. Historical details remain in GitHub Releases and FOLLOWUP.md.
